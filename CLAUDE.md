# Règles du dépôt « simulation » (Baldé, formateur IRAM Boké)

## Organisation
- Un dossier par application. Ne jamais modifier ni écraser les autres dossiers.
- README à la racine : liste des applis avec leurs liens GitHub Pages.

## Chaque application
- D'abord une version web (ordinateur + téléphone), partageable par lien.
- Écran adapté au téléphone : zoom, pincement, déplacement au doigt.
- Simulations en 3D, claires et professionnelles, textes en français.
- Ensuite l'APK, publié dans les Releases GitHub (pas dans le dépôt).

## Qualité
- Analyser, corriger les erreurs et tester avant de livrer, sans demander la permission à chaque correction.
- Pas de failles de sécurité.
- À la fin : commit + push sur main, puis donner le lien GitHub Pages.

## Économie de jetons
- Ne lire que les fichiers utiles à la tâche, jamais tout le dépôt.
- Réponses courtes : résumer ce qui a été fait en quelques lignes, sans réafficher le code complet.
- Modifier seulement les lignes nécessaires, ne pas réécrire un fichier entier.
- Réutiliser le code des applis existantes plutôt que tout recréer.
